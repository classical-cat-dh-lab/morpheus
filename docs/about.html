Morph

About Morph

Morph brings Gregory Crane’s Morpheus, developed for the Perseus Digital Library at Tufts University, into a browser that can work offline. Classical Cat Digital Humanities Lab maintains this independent adaptation.

The Rust beta

Version 0.1.0 runs the accepted Rust preservation of the original analysis program through WebAssembly. Its words, stems, endings and rules come from the original PerseusDL source snapshot. This is a reconstruction from retained sources, not a claim to reproduce the exact program and database currently deployed by Tufts.

Morph displays possible morphological analyses with definitions from the complete, uncollated Perseus LSJ and Lewis & Short editions. Text view preserves your passage; select any word to see its meanings and forms, or switch to List view. Contextual disambiguation and scholarly corrections are not included. Errors and gaps in the original analyses remain possible.

Input and results

For Greek, Reading text mode converts Unicode letters, accents and breathings to Beta Code. For Latin, it removes macrons and breves only from the input delivered to the program. Punctuation separates words. Original input mode accepts literal ASCII, one word per line. Unsupported characters produce a visible error rather than being silently discarded.

The original input and delivered bytes are kept in the downloadable execution record. Display options expose the program’s unchanged output and diagnostics. Candidate order and duplicate analyses are retained.

This edition accepts up to 1,000 lines, 64 KiB per run and 48 ASCII bytes per line. These bounds protect the original fixed-size buffers. Stop analysis cancels the current worker; the next lookup starts with fresh program state.

Dictionary entries

Greek lemmas link to LSJ; Latin lemmas link to Lewis & Short. The frozen Perseus XML files supply the full entries and their original identifiers. Short excerpts are reading aids selected from marked text; the complete entry preserves the context and citations. LSJ Greek Beta Code is displayed as Unicode. No scholarly corrections have been made.

Explicit homonym numbers constrain the dictionary match. Without a number, several entries may appear. An unmatched lemma is shown as missing; the application does not guess a different lemma, strip compound prefixes or silently choose a homonym. These editions and the small presentation adapter are independent of the frozen Rust engine. This is not a claim of matching the currently deployed Perseus dictionary database.

Known reconstruction limits

The original Latin build recipe names a verb input, vbs.mpi, that is absent from the retained source history. This edition explicitly rebuilds from the four available original verb inputs. It does not fill the gap with a different project’s data.

Necessary portability changes address overlapping memory copies and incompatible function-call signatures. The reference runtime fixes the sorting-library implementation because the original does not define the order of equal lemma keys. The Rust core has passed the recorded raw-I/O and internal-behavior qualification against that portable reference, including reproduction of the original retry-memory defect. Its source and artifacts are frozen; frontend refinement continues toward 1.0. The source includes the exact build and comparison evidence.

Offline use and independent copies

For regular use, choose Save for offline, wait for Ready offline, then install Morph using your browser’s Install app or Add to Home Screen command. All required application files, fonts, morphology data and both complete dictionaries are verified before activation. Update & offline provides explicit update checks, which download only a manifest. Updates reuse unchanged verified files and test the saved analyzer; choose Reload with update when ready. Interrupted downloads retain the previous complete version. A browser may still clear stored data; PWA installation alone does not guarantee a complete copy.

Source and static application downloads let you retain and host the software independently. A static HTTPS host can serve the same application. Lookup input stays on your device; the application has no analytics or remote analysis service.
