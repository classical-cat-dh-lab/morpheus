Morph

About Morph

Morph brings Gregory Crane’s Morpheus, developed for the Perseus Digital Library at Tufts University, into a browser that can work offline. Classical Cat Digital Humanities Lab maintains this independent adaptation.

The engineering edition

Version 0.0.1 runs the original C analysis program through WebAssembly. Its words, stems, endings and rules come from the original PerseusDL source snapshot. This is a reconstruction from retained sources, not a claim to reproduce the exact program and database currently deployed by Tufts.

Morph displays possible morphological analyses and original lemma labels. It does not yet include dictionary definitions, contextual disambiguation or scholarly corrections. Errors and gaps in the original analyses remain possible.

Input and results

For Greek, Reading text mode converts Unicode letters, accents and breathings to Beta Code. For Latin, it removes macrons and breves only from the input delivered to the program. Punctuation separates words. Original input mode accepts literal ASCII, one word per line. Unsupported characters produce a visible error rather than being silently discarded.

The original input and delivered bytes are kept in the downloadable execution record. Display options expose the program’s unchanged output and diagnostics. Candidate order and duplicate analyses are retained.

This edition accepts up to 1,000 lines, 64 KiB per run and 48 ASCII bytes per line. These bounds protect the original fixed-size buffers. Stop analysis cancels the current worker; the next lookup starts with fresh program state.

Known reconstruction limits

The original Latin build recipe names a verb input, vbs.mpi, that is absent from the retained source history. This edition explicitly rebuilds from the four available original verb inputs. It does not fill the gap with a different project’s data.

Necessary portability changes address overlapping memory copies and incompatible function-call signatures. The reference runtime fixes the sorting-library implementation because the original does not define the order of equal lemma keys. Full preservation qualification and a later Rust implementation remain work toward 1.0. The source includes the exact build and comparison evidence.

Offline use and independent copies

Choose Save for offline and wait for Ready offline. All required application files, fonts and morphology data are verified before activation. Interrupted downloads retain the previous complete version. A browser may still clear stored data; PWA installation alone does not guarantee a complete copy.

Source and static application downloads let you retain and host the software independently. A static HTTPS host can serve the same application. Lookup input stays on your device; the application has no analytics or remote analysis service.
